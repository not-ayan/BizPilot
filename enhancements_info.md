## Comprehensive Feature Log

### 1. Core Utilities & Services

- **Gemini API Integration in [gemini.py](file:///d:/whatsapp%20automation/app/services/gemini.py)**:
  - Upgraded the AI broadcast promotion formatter to use the latest `gemini-2.5-flash` model.

### 2. Styling & Formatting Enhancements
- **Premium Branding in [pdf_generator.py](file:///d:/whatsapp%20automation/app/services/pdf_generator.py)**:
  - Re-designed PDF invoice layouts and product catalogues with proper page spacing (0.5 in margins), neat borders, and a premium **Deep Navy Blue (#1B365D)** and **Slate Grey (#64748B)** color scheme.
- **Structured WhatsApp Layouts in [state_machine.py](file:///d:/whatsapp%20automation/app/services/state_machine.py)**:
  - **User Profile**: Nicely structured with horizontal section dividers (`━━━━━━━━━━━━━━━━━━`), bold headers, and custom phone number spacing.
  - **Purchase History**: Renders invoices, items, and precise remaining warranties using indented bullet sub-tree formatting (`└─`).
  - **Menus & Support Tickets**: Enhanced greeting fallback and talk-to-owner flows with typography accents and helpful tips.

### 3. Workflows & State Machine Routing
- **Sales Flow Re-ordering**:
  - Prompts for customer phone first. If the customer is registered, displays their profile summary and asks the admin to confirm using the saved name or inputting a new one. Updates the name in the database if edited.
- **Admin Chat Forwarding**:
  - Configured the state machine so that when an admin replies with a non-command message in `STATE_IDLE`, the message is forwarded to the active customer's support ticket chat, establishing a direct chat session.
- **Opt-Out & Broadcast Navigation**:
  - Appends an opt-out notice automatically to all broadcast customer messages.
  - Configured the broadcast's `View Catalogue` button to directly trigger the PDF catalogue generation and delivery flow (`cust_menu_catalogue`) instead of forcing the user back to the main menu.

### 4. Analytical Reports & Excel Exports
- **Excel Report Generators in [report_generator.py](file:///d:/whatsapp%20automation/app/services/report_generator.py)**:
  - Created `generate_customer_excel` and `generate_product_excel` using the `openpyxl` library to write native `.xlsx` workbooks with auto-fit column widths.
  - Updated the report menus in [state_machine.py](file:///d:/whatsapp%20automation/app/services/state_machine.py) to offer **"Customer List (Excel)"** and **"Product List (Excel)"**.
  - Files are uploaded to Meta with the official spreadsheet MIME type (`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`).
- **Database Casting Bug Fix**:
  - Replaced SQL-casting `func.cast(start_dt, func.timestamp)` inside [report_generator.py](file:///d:/whatsapp%20automation/app/services/report_generator.py) with direct python `datetime` comparisons, resolving the SQLAlchemy `AttributeError` exception.

### 5. Background Scheduler
- Added the `check_inactive_tickets_job` to [scheduler.py](file:///d:/whatsapp%20automation/app/services/scheduler.py) running every 5 minutes. Tickets with no activity for 1 hour are automatically closed, and notifications are sent to both customer and admins.

### 6. Admin Manual Intervention Pause
- **Temporarily Silence Bot on Manual Admin Reply**:
  - Implemented sent message tracking in [whatsapp.py](file:///d:/whatsapp%20automation/app/services/whatsapp.py) using a message ID cache.
  - Intercepts webhook status updates in [webhook.py](file:///d:/whatsapp%20automation/app/routers/webhook.py) to detect manual replies sent by the owner/admin from linked devices (not generated by the bot).
  - Pauses bot replies for the customer by updating `bot_paused_until` to `1 hour` in the future.
  - Automatically checks `bot_paused_until` in [state_machine.py](file:///d:/whatsapp%20automation/app/services/state_machine.py) and ignores customer messages while paused, resuming replies automatically after 1 hour.

## Running the Project

You can run the automation system locally or via Docker:

### 1. Run Locally (Recommended for Development)
Ensure your virtual environment is activated and dependencies are installed, then run the Uvicorn server:
```bash
# Using uv (fastest)
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# Using standard virtual environment
.venv\Scripts\uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 2. Run via Docker Compose
To run the server along with the PostgreSQL database in containers:
```bash
docker-compose up --build
```
